# Release checklist

- [x] Executable package and actual CPU pilot artifacts.
- [x] Explicit incomplete-study status and source references.
- [x] Raw data, environments, and caches excluded from source archive.
- [ ] Confirm personal authorship in CITATION.cff and copyright choice.
- [ ] Create the public repository only after owner authorization.
- [ ] Review source and run the supplied GitHub Actions on the target host.
- [ ] Attach the evidence archive or select Git LFS for checkpoints and prediction arrays.
- [ ] Review upstream dataset/dependency terms before redistribution.
- [ ] Add repository URL and a versioned release; do not invent a DOI.
- [ ] Execute remaining full-data, architecture, dataset, and ablation comparisons before stronger claims.
