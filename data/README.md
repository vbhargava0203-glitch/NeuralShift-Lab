# Dataset storage

Use the download-data CLI to fetch official torchvision sources. Raw data is ignored by Git and excluded from delivery archives. Fashion-MNIST uses its official maintainer GitHub mirror with torchvision MD5 verification; CIFAR-10 uses the torchvision official Toronto source. Dataset split IDs, source SHA256 checksums and class counts are saved per run. Dataset licenses are independent of the MIT software license; review the upstream terms before redistribution.
